# 按 MAC 自定义客户端主机名

在“客户端”表格打开某条记录的操作菜单，选择“自定义主机名”，填写名称并保存。支持中文和空格，最多 64 个字符。同一 MAC 对应的 IPv4／IPv6 或其他 IP 记录共用该名称，MAC 大小写及常见分隔符会统一处理。

名称只用于 UI 显示，不修改 DHCP、设备主机名、SmartDNS 配置或服务端数据库。没有有效 MAC 的记录不能设置，零 MAC、广播 MAC 和格式错误的 MAC 不作为设备标识。设备使用随机 MAC 或更换网卡后，需为新的 MAC 重新设置。

保存后，“客户端”的主机名列优先显示自定义名称，悬停可查看原始名称。编辑框留空后保存可移除该设备的自定义覆盖。“恢复原始主机名”将名称草稿清空，再点击保存生效，保留所选设备图标；取消不保存。主机名筛选仍使用服务端原始主机名，不能用本地显示名筛选全量客户端。

## 设备图标与近期活跃状态

图标选择使用紧凑的单行下拉框，菜单内显示图标及名称；选择“自定义 Iconify 图标”后才展开图标名称输入。

同一编辑框内可选择 Apple、Apple TV、Windows、Android、Huawei、Xiaomi、Radio、Debian、Camera、VMware、Synology DSM、MikroTik、QNAP、通用 NAS、Unraid 或通用设备。16 个 Iconify 预设的图形数据内置于前端，离线可显示；也可填写 `图标集:图标名`，其他图标需要访问 Iconify API，未加载或加载失败时显示通用设备图形。选择“无图标”可隐藏图标。未设置时默认显示通用设备图标。预设配色分别适配浅色和深色主题，名称文字不随状态变灰。

可通过色板或 `#RRGGBB` 输入自定义图标颜色，内置和自定义 Iconify 图标均适用。自定义颜色在深浅主题中保持一致，仅用于活跃状态；无查询和未知状态继续使用统一中性色。清空颜色或点击“恢复配色”后恢复预设的深浅主题配色。切换图标及恢复主机名保留颜色；无图标时仍保留颜色偏好，名称和复制信息不隐藏。保存后客户端和查询日志同步使用颜色。

图标按 MAC 保存，名称与图标可独立设置，包括只设图标、不设名称。可选 `icons`、`iconColors` 映射与原有 `names` 映射放在同一个 v1 存储记录中，一次写入同时保存名称、图标和颜色，旧名称数据无须迁移。`icons` 中空字符串表示“无图标”，删除该 MAC 的图标项表示使用通用设备默认值。`iconColors` 以 MAC 保存六位十六进制颜色，删除该项恢复默认；旧数据缺少该字段时使用默认配色。该功能显示在客户端表格、编辑框及查询日志的客户端列中。

查询日志当前页有至少 4 个不同 IP 时，先读取一页最多 256 条客户端记录，按完整 IP（含等价 IPv6 规范化）共享名称、图标和活跃状态；不会连续翻页扫描全部客户端。少于 4 个不同 IP 时直接按 IP 查询，避免大列表传输。该页未覆盖的 IP 使用原有精确查询，列表失败时也可回退。结果按 IP 缓存，前台每 30 秒刷新、后台不持续轮询；成功响应的本地接收时间作为活跃时钟参考。请求失败时保留缓存的名称和图标，但状态仍显示未知；没有匹配记录也显示未知。图标状态来自当前客户端记录，不表示历史在线情况。复制和筛选始终保留原始完整 IP。

查询日志的自动客户端列宽按当前页实际显示的名称或 IP 简写、图标、未知标记及间距计算，不再为最长示例 IP 固定留白。首次匹配名称完成后确定宽度；保存名称或图标设置会重新计算。自动宽度最多为 280px，长名称省略显示，完整内容仍可悬停查看和复制；多余空间由域名列使用。手动模式继续使用已保存的列宽。

面板日期时间统一显示为 `YYYY/MM/DD HH:mm:ss`，例如 `2026/10/27 19:06:20`。查询日志的时间列按相同分隔符测量宽度，客户端和查询日志的日期筛选框显示到分钟。此调整仅改变显示格式，仍沿用原有显示时区和后台时间戳。

查询日志表头采用原项目默认布局。数据行的域名、客户端、时间和 ID 左对齐；类型、组、阻止状态、缓存命中、Ping、查询耗时、回应码及操作居中，数值使用等宽数字。紧凑、舒适、宽松模式的单元格左右留白分别为 4px、8px、12px（16px 根字号），复制按钮不增加横向留白。自动列宽的数值使用同一个真实字体探针批量测量，避免逐条写入再强制布局；尺寸和完整值的显示约定保持一致。

自动模式下短字段使用稳定的 8px 宽度档位；表头、完整时间和当前页所有查询耗时均参加测量，较大数值可扩宽。刷新时保持已经扩展的列宽，避免数据变短时来回跳动。切页、筛选、调整间距或修改设备设置后会重新计算；也可点击刷新按钮旁的“重新适配列宽”主动收回留白。手动模式保留拖拽偏好，此时重新适配按钮禁用。域名列独占剩余空间；窄屏保留可读宽度并在表格内横向滚动，长域名和长名称仍可悬停及复制完整内容。

Ping 按常见两位数加一位小数（如 `99.9 ms`）确定紧凑宽度，不为极值或实际超长值扩宽。较大 Ping 在单元格内悬停或键盘聚焦时往返滚动，提示显示完整值，复制仍保留完整原始数值。触屏或启用减少动态效果时使用原生横向滑动，不自动播放动画。普通数值与无延迟数据的破折号仍居中显示。

活跃状态根据每条客户端记录的 `last_query_timestamp`（毫秒）计算：最近 5 分钟（含边界）有 DNS 查询显示预设亮色，超过 5 分钟显示灰色。状态表示该 IP 记录的近期 DNS 活跃情况，不等同于设备在线／离线；同 MAC 的多条 IP 记录共用图标，但活跃时间分别计算。无有效时间、时间在未来或获取客户端数据失败时显示未知状态及问号。悬停可查看状态、最后查询时间与判定说明。客户端页面在前台每 30 秒刷新当前筛选和分页的数据，并更新状态时钟；后台不持续轮询，不额外扫描所有客户端。

内置图标来源、作者及各图标集许可见 `/licenses/client-device-icons.txt` 与同目录的许可文件。Iconify 框架的许可不替代图标集各自的许可。

活跃状态判定使用周期时钟与成功响应接收时间中的较新值。刷新取得的新查询时间可能晚于上一次周期时钟，此时不会再误判为未来时间而显示问号；后续仍随时钟推进过期。真正的客户端查询失败、缺失记录、无效时间及晚于本地参考时间的服务器时间仍显示未知状态 `?`，接口失败时保留缓存中的名称和图标。客户端表格与查询日志使用相同规则。

仪表盘“最多查询客户端”继续按现有查询次数排名，统计及日志跳转仍以 IP 为准，不合并同一 MAC 的多条 IP 统计。存在自定义名称时，UI 只对榜单 IP 通过现有客户端接口补查当前 MAC，匹配到配置后在同一行显示主机名和较小的灰色 IP。过长的名称、IPv6 或域名会省略显示，悬停或聚焦链接可查看完整内容。左右榜单共用单行行高和留白，桌面端卡片等高；手机端上下排列并按内容确定高度。找不到 MAC、没有匹配名称或查询失败时保留原 IP，不影响统计和跳转。不扫描全部客户端或历史日志，查询结果在内存复用；超过一分钟后重新进入仪表盘时会重新查询，页面停留期间不会按分钟轮询。

映射基于服务端当前客户端记录，不能追溯历史时刻某个 IP 所属设备。经过路由或其他转发时，服务端可能无法获知真实终端 MAC，此时无法按该设备设置名称。

配置存储在当前浏览器、当前访问地址（协议／主机／端口）的 localStorage，键为 `smartdns-webui:client-names:v1`。同地址其他窗口会同步；换设备、浏览器或访问地址不会自动同步。清除站点数据后自定义名称会被删除。

配置读写失败会在编辑框提示，保存失败不会关闭编辑框或覆盖现有名称。保存时读取最新配置并合并当前 MAC，避免覆盖其他窗口刚编辑的其他设备。
