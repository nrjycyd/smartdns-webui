# 设置备份

设置 → 备份，可导出或导入当前浏览器的已保存自定义参数，无须修改服务端。

包含客户端名称、图标及颜色、分组外观、表格列宽/显隐/每页条数、密度与列宽模式、缓存列表每页条数、显示及统计时区、语言、主题。

不包含登录令牌、密码、服务器规则、服务器配置、查询日志、未保存的编辑内容及默认 group-colors.json 文件。请在备份前保存编辑。

导出格式：JSON，format 为 smartdns-webui-settings，version 为 1，settings 为允许的存储键与字符串或 null 的映射。null 表示恢复该项默认设置。备份在不同地址、端口、浏览器间可导入。

导入流程：选文件 → 校验 → 确认导入 → 自动刷新。仅替换文件列出的设置；完整导出含所有支持项，缺失的存储值记录为 null。旧版分组外观 JSON 只替换分组外观，不影响其他设置。不支持未来版本或未知存储键，文件大小不超过 1 MiB。写入失败尝试还原本次触及的设置，并报告回滚失败。

原分组外观页面的重新加载默认文件、恢复全部默认、导入自定义、导出自定义操作已移除；保存、取消、恢复当前分组功能保留。
